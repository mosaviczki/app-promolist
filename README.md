# Sobre o aplicativo:
O Aplicativo tem tela de login e cadastro na qual a autenticação é feita pelo firebase.
<br/>
O Aplicativo é um conjunto de to do list de supermercado com a visualização dos melhores preços dos supermercados perto da sua localização
